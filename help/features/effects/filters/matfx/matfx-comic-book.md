## Descrizione

Il filtro MatFX Comic Book stilizza i materiali con un aspetto ispirato ai fumetti.

Viene utilizzato sui livelli texture per creare uno stile di rendering grafico e illustrato con ombreggiatura semplificata e trattamento visivo audace.

## Input

| Nome di input | Descrizione |
| --- | --- |
| <b>Occlusione ambientale:</b> Scala di grigi | Usa la mappa di occlusione ambientale eseguita i baking. |
| <b>Curvatura:</b> Scala Di Grigi | Utilizzate la mappa di curvatura eseguita i baking. |
