# Aggiungere percorsi di risorsa modificando manualmente le preferenze

È possibile aggiungere ulteriori percorsi Shelf o Assets personalizzati senza aprire l&#39;applicazione.

A tale scopo, è necessario modificare le preferenze dell’applicazione (memorizzate in modo diverso per piattaforma). Una volta aggiunto, il nuovo scaffale dovrebbe apparire nell&#39;elenco degli scaffali nelle preferenze principali. Per ulteriori dettagli, vedere questa pagina: [Configurazione librerie](../../../interface/settings/libraries-configuration.md)

>[!NOTE]
>
> Percorso di rete non supportato. Per evitare problemi, utilizzare un percorso attivato. Vedere: [Caricamento di file da una rete](../../../technical-support/workflow-issues/project-issues/loading-files-from-a-network.md).
