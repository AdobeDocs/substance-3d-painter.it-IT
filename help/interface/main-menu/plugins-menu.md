# Menu dei plug-in JavaScript e Python

![](../../assets/plugins-javascript.png)

I menu JavaScript e Python elencano tutti i plug-in caricati da Painter all&#39;avvio. I plug-in vengono suddivisi in due menu in base all’API di scripting utilizzata (Javascript o Python).

Ogni plug-in individuato dall&#39;applicazione aggiungerà una voce nel rispettivo menu per accedere a funzioni aggiuntive. Nei menu, ogni plug-in ha le seguenti opzioni:

* **disabilitare/abilitare**: attiva o disattiva il plug-in.
* **ricarica**: ricarica il plug-in nel caso in cui lo script sia stato aggiornato durante l&#39;esecuzione dell&#39;applicazione.
* **configura**: se supportato dal plug-in, visualizza la funzione o la finestra per configurare il plug-in.
* **informazioni su**: se supportato dal plug-in, visualizza le informazioni sul plug-in.

Per informazioni sui plug-in predefiniti forniti con Painter o su come crearne di nuovi, consultate la pagina dedicata [Plug-in](../../features/plugins/plugins.md).
