# Simmetria speculare

La simmetria a specchio è una simmetria assiale che può essere attivata nella barra degli strumenti contestuale:

![](../../assets/symmetry-mirror.png)

## Usate il manipolatore per posizionare l’asse di simmetria

È possibile accedere alle impostazioni di visualizzazione Simmetria dal <b>pulsante Impostazioni simmetria</b> nella barra degli strumenti contestuale nella parte superiore della vista 3D. Sotto le impostazioni di visualizzazione, è possibile attivare e personalizzare il manipolatore. Trascinate le maniglie del manipolatore nella vista 3D per modificare la posizione dell’asse di simmetria.

![](../../assets/MirrorSymmetryManip.png)

## Parametri simmetria speculare

![Schermata delle impostazioni di simmetria a specchio](../../assets/MirrorSymmetry-2.png){width="300px"}

| *Parametro* | *Descrizione* |
| --- | --- |
| <b>Asse</b> | Definisce l’asse della scena utilizzato per eseguire la simmetria. |
| <b>Posizione asse</b> | Definisce l&#39;offset dell&#39;asse nel progetto. Questo valore può essere modificato con i cursori o con il manipolatore (vedere sopra). |
| <b>Mostra piano</b> | Se questa opzione è attivata, nella finestra della vista sarà visibile un piano trasparente per delimitare ogni lato della simmetria speculare. |
| <b>Mostra intersezione</b> | Se questa opzione è attivata, verrà disegnata una linea sulla trama nella finestra della vista per delimitare ogni lato della simmetria speculare. |
| <b>Mostra cursore</b> | Se questa opzione è attivata, sull&#39;altro lato della simmetria verrà visualizzato un secondo cursore per indicare quando verrà eseguito il disegno. |
| <b>Nascondi durante disegno</b> | Se questa opzione è attivata, il secondo cursore viene nascosto mentre è in corso l’operazione di disegno (fino al rilascio del clic del mouse). |
| <b>Dimensione manipolatore</b> | Controlla le dimensioni del manipolatore nella finestra della vista. |
