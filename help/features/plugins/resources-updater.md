# Resources Updater

![](../../assets/resources-updater-window.png)

Il plug-in **Resources Updater** consente di sfogliare le risorse presenti nel progetto attualmente aperto.\
Ogni risorsa può essere sostituita da un&#39;altra presente nello scaffale. Le risorse visualizzate in rosso sono considerate &quot;obsolete&quot;, significa che una versione diversa della stessa risorsa è presente nello scaffale ed è (probabilmente) più recente.
