# Le risorse dello scaffale non sono più disponibili dopo l’aggiornamento alla versione 7.2

Questa pagina spiega perché le risorse potrebbero essere scomparse e come ripristinarle.

Dopo l’aggiornamento alla versione 7.2 (o a una versione più recente), è possibile che alcune risorse personalizzate presenti nello scaffale, come alfa, filtri, materiali, materiali avanzati o persino maschera avanzata, siano scomparse. Questo perché questa nuova versione ha reimpostato le preferenze e i file si trovano ora in una cartella diversa. Le risorse precedenti vengono ignorate e possono essere ripristinate solo copiando manualmente i file. A tale scopo, consulta la [guida alla migrazione](../../../pipeline-and-integration/resource-management/preferences-and-content-migration.md).
