## Descrizione

Il filtro Speculare è un filtro simmetria per copiare una parte dell’input.

Viene utilizzato su un livello texture (colore) o una maschera per riflettere materiali completi, maschere, forme, ecc. in base all&#39;asse mirror.

</td>
</tr>
</table>

>[!NOTE]
>
> Il filtro a specchio funziona nello spazio UV, quindi può essere utile aprire il Vista 2D nella **finestra della vista**.

<a name="parameters"></a>

## Parametri

| Nome parametro | Descrizione |
| --- | --- |
| <b>Debug visualizzazione:</b> | Attiva/disattiva la visualizzazione del debug. |
| <b>Modalità:</b> | Selezionare la modalità di mirroring. |
| <b>Offset asse X:</b> | Regolate lo scostamento dell’asse X. |
| <b>Offset Y asse:</b> | Regolate lo scostamento dell&#39;asse Y. |
| <b>Inverti asse X:</b> | Attiva/disattiva l’inversione sull’asse X. |
| <b>Inverti asse Y:</b> | Attiva/disattiva l’inversione sull’asse Y. |
| <b>Tipo angolo:</b> | Selezionate la modalità di gestione degli angoli specchiati. |
