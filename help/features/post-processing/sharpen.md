# Nitidezza

![](../../assets/v12_post_sharpen.jpg)

Migliora i bordi e i dettagli più fini dell&#39;immagine per aumentare la nitidezza percepita.

| <b>Parametro</b> | <b>Descrizione</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>Importo</b> | Controlla l’intensità dell’effetto nitidezza. Più alti sono i valori, maggiore sarà il contrasto tra i bordi. |
| <b>Diametro</b> | Imposta le dimensioni dell’effetto di nitidezza in pixel. I valori più bassi rendono più nitidi i dettagli minuti, mentre i valori più alti influiscono sui bordi più ampi e possono creare un effetto più pronunciato. |
