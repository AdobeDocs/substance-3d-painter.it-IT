# Errore: nessun disco nell&#39;unità

In Windows, a volte si verifica questo errore:

&quot;L&#39;unità non contiene alcun disco. Inserire un disco nell&#39;unità X.&quot;

![](../../../assets/disk-drive-error.png)

Per eliminare l&#39;errore è necessario eseguire alcuni controlli:

* Verificare che l&#39;impostazione delle lettere di unità sia corretta (vedere <https://support.microsoft.com/en-us/kb/330137> )
* Verifica che qualsiasi percorso precedente utilizzato in Substance 3D Painter sia valido (come l&#39;elenco &quot;File recenti&quot;)
