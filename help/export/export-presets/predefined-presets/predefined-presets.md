# Modelli di output predefiniti

I Modelli di output predefiniti non possono essere modificati, ma vengono generati da Substance 3D Painter. I Modelli di output predefiniti vengono visualizzati nella parte superiore dell&#39;elenco a discesa <b>Modelli di output </b>nella <b>scheda Impostazioni</b> della <b>finestra Esporta</b>.

Di seguito è riportato un elenco dei predefiniti non modificabili disponibili:

* Visualizzazione 2D
* Canali documento + Normale + AO (nessun Alpha)
* Canali documento + Normale + AO (con Alpha)
* Sketchfab
* Substance 3D Stager
* [USDz (Apple AR)](usd-pbr-metal-roughness-preset.md)
* Rugosità metallo glTF PBR
* glTF PBR Rugosità metallo + texture Spostamento (sperimentale)
