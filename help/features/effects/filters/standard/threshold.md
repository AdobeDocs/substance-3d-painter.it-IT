## Descrizione

Il filtro Soglia restituisce il bianco quando vengono soddisfatti i criteri di confronto impostati nel parametro Modalità per il valore del pixel di input relativo al valore Soglia. È simile alla scansione dell’istogramma, ma con un contrasto sempre al massimo, fornendo un modo più veloce e preciso per ottenere risultati simili.

Viene utilizzato direttamente su un livello di riempimento o su una maschera (output in bianco e nero) per creare rapidamente una maschera a contrasto elevato da canali specifici.

## Parametri

| Nome parametro | Descrizione |
| --- | --- |
| <b>Soglia:</b> | Regolate il valore di luminanza rispetto al quale viene confrontato il valore dei pixel di input. |
| <b>Modalità:</b> | Selezionare il criterio di confronto utilizzato per il valore di soglia: Maggiore, Maggiore o uguale, Minore o Minore o uguale. |
| <b>_modalità:</b> | Seleziona il valore della modalità interna. |
| <b>_soglia:</b> | Regolate il valore di soglia interno. |
| <b>_threshold_min:</b> | Regolate il valore di soglia minimo interno. |
| <b>_threshold_max:</b> | Regolate il valore di soglia massimo interno. |
