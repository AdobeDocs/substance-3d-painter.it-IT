# Impossibile trascinare i file sullo scaffale

In **Windows 8 e Windows 10** , se si esegue Substance 3D Painter in modalità amministratore, il livello di protezione del software sarà probabilmente superiore a quello di Esplora risorse. Pertanto, Windows non consente di trascinare i file tra queste applicazioni.

Per risolvere questo problema, puoi:

* Esegui Substance 3D Painter normalmente (senza diritti di amministratore).
* Disabilita Controllo dell&#39;account utente (opzione **non consigliata**).

>[!NOTE]
>
> È inoltre possibile importare le risorse semplicemente aprendo la finestra di importazione:
> 
> 1. Fare clic sul menu &quot;File&quot;
> 1. Scegliere &quot;Importa risorse...&quot;
> 1. Nella finestra Importazione, fare clic su &quot;Aggiungi risorse&quot; per selezionare i file
