# Modelli di output

![](../../assets/preset-list.png)

Substance 3D Painter dispone di due tipi di Modelli di output che possono essere utilizzati per controllare il comportamento del processo di esportazione.

* [I Modelli di output predefiniti](default-presets.md) sono progettati per funzionare con specifiche applicazioni o flussi di lavoro 3D e sono disponibili nella <b>scheda Modelli di output</b> della <b>finestra Esporta</b>. È possibile duplicare e modificare un modello predefinito o creare un modello personalizzato partendo da zero.
* Impossibile modificare [Modelli di output predefiniti](../../export/export-presets/predefined-presets/predefined-presets.md). I modelli predefiniti vengono visualizzati nella parte superiore dell&#39;elenco a discesa <b>Modello di output</b> nella <b>scheda Impostazioni</b> della <b>finestra Esporta</b>.
