# Filtra per percorso

**Filtra per percorso** è una sezione aggiuntiva che può essere utilizzata per spostarsi tra le risorse. Ha la stessa struttura dei breadcrumbs, il che significa che consente di visualizzare il percorso/posizione delle risorse.

![](../../assets/01-01-panel.jpg)

Per impostazione predefinita, è attivata l&#39;opzione **Nascondi cartelle non applicabili** che consente di nascondere le cartelle vuote dall&#39;interfaccia utente. Questa funzione è utile se, ad esempio, combini Filtra per percorso con una parola di ricerca specifica o se selezioni un tipo di risorsa: consente di visualizzare solo le posizioni pertinenti che contengono la ricerca.

![](../../assets/01-02-hideempty.gif)
