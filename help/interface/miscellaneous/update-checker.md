# Verifica aggiornamenti

![](../../assets/update-cc.png)

Puoi verificare la disponibilità di aggiornamenti per Substance 3D Painter da Creative Cloud Desktop. Seleziona la scheda App, quindi la sezione App installate. Se un aggiornamento è pronto per il download, verrà visualizzato **Aggiornamento disponibile** sotto il nome dell&#39;app.

Puoi accedere alle note sulla versione per la versione corrente aprendo Painter e utilizzando **Guida > Note sulla versione**.
