# Menu File

![](../../assets/file-menu.png){width="150px"}

Il menu File contiene le azioni per creare e salvare i progetti, nonché le azioni per esportare e importare le risorse in un progetto.

| Azione | Descrizione |
| --- | --- |
| **Nuovo** | Apri la finestra di creazione del nuovo progetto. Per ulteriori informazioni, vedere [Creazione di progetti](../../getting-started/project-creation.md). |
| **Apri** | Aprite un file di progetto esistente sul disco. |
| **File recenti** | Elenca tutti i progetti aperti di recente. |
| **Apri campione** | Apri uno dei progetti di esempio forniti con l&#39;applicazione. |
| **Chiudi** | Chiudete il progetto aperto. |
| **Salva** | Salva il progetto corrente in posizione. |
| **Salva e compatta** | Salva il progetto corrente in posizione e comprimilo (riduci l’ingombro su disco). |
| **Salva con nome** | Salva il progetto corrente con un nuovo nome e in una nuova posizione. |
| **Salva come copia** | Salva il progetto corrente con un nuovo nome e in una nuova posizione come copia e mantieni aperto il progetto corrente. |
| **Salva come modello** | Salva le impostazioni correnti del progetto in un file modello utilizzabile per un nuovo progetto. |
| **Pulito** | Rimuovi tutte le risorse inutilizzate dal progetto corrente (saranno attive dopo il prossimo **salvataggio**). |
| **Importa risorse** | Aprire la finestra Importa risorse. |
| **Esporta trama** | Aprite la finestra di esportazione della trama che consente di esportare il progetto corrente come file di modello 3D. |
| **Esporta texture** | Aprite la finestra esportazione texture che consente di esportare il progetto corrente come texture bitmap. |
| **Invia a** | Elenca tutte le azioni **Invia a** per inviare un progetto a un&#39;altra applicazione. |
| **Esci** | Chiudi l’applicazione. Se il progetto corrente contiene modifiche non salvate, verrà visualizzato un messaggio. |

>[!NOTE]
>
> Il salvataggio di un progetto può essere eseguito in due modi:
> 
> * **Incrementale**: metodo predefinito, utilizzato quando si esegue un salvataggio regolare. Solo le informazioni modificate verranno aggiornate nel file di progetto sul disco. Questo metodo consente di salvare molto rapidamente il progetto senza dover riscrivere completamente il file del progetto.
> * **Completo / Compatto**: se viene eseguita un&#39;operazione di pulizia o se il progetto viene salvato con l&#39;azione &quot;Salva e compatta&quot;, il metodo riscriverà completamente il progetto sul disco. Questo metodo consente di eliminare la frammentazione del progetto e di ridurre l&#39;ingombro. Consultate: [I progetti sono molto grandi](../../technical-support/workflow-issues/project-issues/projects-are-really-big.md).
