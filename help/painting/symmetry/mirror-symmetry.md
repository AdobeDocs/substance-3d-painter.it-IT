# Simmetria speculare

La simmetria speculare è una simmetria assiale che può essere attivata nella barra degli strumenti contestuale:

![](../../assets/symmetry-mirror.png)

## Usate il manipolatore per posizionare l’asse della simmetria

È possibile accedere alle impostazioni di visualizzazione della Simmetria dal <b>pulsante Impostazioni Simmetria</b> nella barra degli strumenti contestuale nella parte superiore della visualizzazione 3D. Sotto le impostazioni di visualizzazione, puoi abilitare e personalizzare il manipolatore. Trascinate le maniglie del manipolatore nella vista 3D per modificare la posizione dell’asse della simmetria.

![](../../assets/MirrorSymmetryManip.png)

## Parametri simmetria speculare

![Schermata delle impostazioni della simmetria mirror](../../assets/MirrorSymmetry-2.png){width="300px"}

| *Parametro* | *Descrizione* |
| --- | --- |
| <b>Asse</b> | Definisce l’asse della scena utilizzato per eseguire la simmetria. |
| <b>Posizione asse</b> | Definisce l&#39;offset dell&#39;asse nel progetto. Questo valore può essere modificato con i cursori o con il Manipolatore (vedi sopra). |
| <b>Mostra piano</b> | Se questa opzione è attivata, nella finestra della vista sarà visibile un piano trasparente che delimita ciascun lato della simmetria specchiata. |
| <b>Mostra intersezione</b> | Se questa opzione è attivata, verrà tracciata una linea sulla trama nella finestra della vista per delimitare ogni lato della simmetria specchiata. |
| <b>Mostra cursore</b> | Se questa opzione è attivata, sull’altro lato della simmetria verrà visualizzato un secondo cursore per indicare quando verrà eseguito il disegno. |
| <b>Nascondi durante disegno</b> | Se questa opzione è attivata, il secondo cursore viene nascosto mentre è in corso l’operazione di disegno (fino al rilascio del clic del mouse). |
| <b>Dimensioni Manipolatore</b> | Controlla le dimensioni del Manipolatore nella finestra della vista. |
