# Misuratore UV

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_uv_checker.png" alt=""/><br><strong>In:</strong> uv, bordo, casuale</td>
    <td style="border: 0;" valign="top"><strong>Descrizione</strong><br>Il generatore di Controllo UV applica al modello un motivo a griglia che consente di individuare con facilità problemi UV quali dilatazione, ridimensionamento irregolare o distorsione. <br><br>Il generatore UV Checker viene generalmente utilizzato direttamente su un livello di riempimento per visualizzare le distorsioni UV.</td>
  </tr>

## Parametri

<table>
  <tr>
    <th>Nome parametro</th>
    <th>Descrizione</th>
  </tr>
  <tr>
    <td><strong>Seed</strong></td>
    <td>Impostate il valore di partenza utilizzato per generare la texture del dirt. <br><ul><li>Fate clic su Casuale per passare a un altro valore di inizializzazione casuale.</li><li>Fate clic sulla matita per visualizzare il valore iniziale corrente e immettete un valore specifico.</li></ul></td>
  </tr>
  <tr>
    <td><strong>Metodo colore controllo</strong></td>
    <td>Selezionate la modalità di assegnazione dei colori:<br><ul><li><strong>Uniforme</strong>: applica lo stesso colore al set di texture.</li><li><strong>Casuale</strong>: applica un colore casuale a ciascuna Isola UV.</li></ul></td>
  </tr>
  <tr>
    <td><strong>Colore controllo</strong></td>
    <td>Imposta il colore del motivo dello strumento di controllo.</td>
  </tr>
  <tr>
    <td><strong>Affianca griglia controllo</strong></td>
    <td>Regola le dimensioni del motivo di controllo.</td>
  </tr>
  <tr>
    <td><strong>Opacità griglia controllo</strong></td>
    <td>Regolate l’opacità della griglia. Con opacità 0, è visibile solo una texture di controllo, senza griglia.</td>
  </tr>
  <tr>
    <td><strong>Colore bordi UV</strong></td>
    <td>Impostate il colore dei bordi UV.</td>
  </tr>
  <tr>
    <td><strong>Larghezza bordi UV</strong></td>
    <td>Regolate la larghezza dei bordi UV.</td>
  </tr>
</table>
