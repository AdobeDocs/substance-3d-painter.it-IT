# Artefatti e difetti sul sistema operativo Mac con GPU personalizzate

>[!WARNING]
>
> Le configurazioni non ufficiali di Apple non sono ufficialmente supportate, il che significa che qualsiasi parte (ad esempio la GPU) che non sia stata venduta originariamente da Apple potrebbe non funzionare correttamente con il software.

Se durante l&#39;esecuzione di una GPU personalizzata con driver personalizzati si verificano problemi, arresti anomali o artefatti su Mac, potrebbe essere utile eliminare **l&#39;elenco corretto** dei file correlati all&#39;applicazione.

Per sapere quale file rimuovere, consulta: [Preferenze e percorso dei dati dell&#39;applicazione](https://helpx.adobe.com/it/substance-3d/unlisted/documentation/spdoc/application-preferences-location-147095594.html).
