# Modelli di output predefiniti

Di seguito è riportato un elenco di Modelli di output aggiuntivi forniti per impostazione predefinita.  I Modelli di output predefiniti possono essere copiati e modificati nella scheda <b>Modelli di output </b>della <b>finestra Esportazione</b>.

>[!NOTE]
>
> È possibile che siano supportati anche altri software non elencati in questa pagina, ad esempio **ottano**. Per ulteriori informazioni, consulta [ecosistema e plug-in](https://experienceleague.adobe.com/it/docs/substance-3d/ecosystem/home).

| *Predefinito* | *Descrizione* |
| --- | --- |
| <b> Amazon Lumberyard </b> | Nome e texture della confezione da importare e utilizzare in Amazon Lumberyard. |
| <b> Arnold (AiStandard) </b> | Predefinito per Arnold (AiStandard shader). |
| <b> Legacy di Arnold UDIM (AiStandard)</b> | Predefinito per Arnold UDIM Legacy (AiStandard). |
| <b>Frullatore (BSDF Basato Su Principled)</b> | Predefinito per Blender (BSDF con principi). |
| <b> Corona </b> | Predefinito per il modulo di rendering Corona. |
| <b> CryEngine 3 </b> | Nome e texture del pacchetto da importare e utilizzare in Cry Engine 3. |
| <b> Dota 2 </b> | Predefinito per il gioco Dota 2 (può essere utilizzato con il modello associato). |
| <b> Keyshot </b> | Predefinito per il modulo di rendering Keyshot. |
| <b>Keyshot 9+</b> | Predefinito per il modulo di rendering Keyshot dalla versione 9 in poi. |
| <b> Studio obiettivo </b> | Predefinito per Lens Studio (per creare risorse per Snapchat). |
| <b>Maxwell (Rugosità metallica)</b> | Predefinito per il modulo di rendering Maxwell utilizzando il flusso di lavoro Rugosità metallica. |
| <b>Maxwell (Lucentezza Specular)</b> | Predefinito per il modulo di rendering Maxwell utilizzando il flusso di lavoro Specular Lucentezza. |
| Mappe trama <b> </b> | Esportate singolarmente gli slot eseguiti i baking della mappa di trama di un set di texture (esportate con la stessa risoluzione del set di texture). |
| <b>Lucentezza Specular non PBR</b> | Assegnare un nome alle texture ed esportarle per un flusso di lavoro di Lucentezza di Specular non PBR. |
| <b> Rugosità metallica PBR</b> | Nome ed esportazione delle texture necessarie per un normale flusso di lavoro PBR per metallizzazione/rugosità. |
| <b> Rugosità metallica PBR (cartella o gruppi di PSD) </b> | Simile a PBR MetalRough, ma crea una cartella aggiuntiva. Questo predefinito è adatto principalmente per essere utilizzato con il formato di file PSD. |
| <b> Lucentezza Specular PBR</b> | Nome ed esportazione delle texture necessarie per un normale flusso di lavoro PBR di Specular/Lucentezza. Le texture vengono convertite dal flusso di lavoro BaseColor/Metallic. |
| <b> Lucentezza Specular PBR (convertita da Rugosità metallica</b> | Convertite i canali Colore di base, Metallico e Rugosità in modo che siano compatibili con il flusso di lavoro Specular/Glissità. |
| <b> Redshift </b> | Predefinito per il modulo di rendering Redshift. |
| <b>Modulo di rendering (pxrDisney)</b> | Predefinito per Renderman con mappe metallizzate e di rugosità. |
| <b>Modulo di rendering (pxrSurface)</b> | Predefinito per Renderman con mappe Diffusa e Specular. |
| <b>Roblox (MaterialVariant)</b> | Predefinito per Roblox con Albedo senza supporto alfa. |
| <b>Roblox (SurfaceAppearance)</b> | Predefinito per Roblox utilizzando Colormap con canali alfa. |
| <b> Ombreggiatura 3D </b> | Predefinito per Ombra 3D. |
| <b>Spark AR Studio</b> | Predefinito per Spark AR Studio. |
| <b>Pipeline di rendering Unity HD (standard metallico)</b> | Predefinito per la pipeline di rendering HD di Unity utilizzando mappe Metalliche e Lucentezze. |
| <b>Pipeline di rendering Unity HD (Specular)</b> | Predefinito per la pipeline di rendering HD di Unity con mappa di specular aggiunta. |
| <b>Pipeline di rendering universale di Unity (standard metallico)</b> | Predefinito per la pipeline di rendering universale di Unity utilizzando mappe metalliche e di Smoothness. |
| <b>Pipeline di rendering universale di Unity (Specular)</b> | Predefinito per la pipeline di rendering universale di Unity con mappe di Specular e Smoothness. |
| <b> motore non reale (compresso) </b> | Texture di nomi e pacchetti da utilizzare nel motore irreale con il minor ingombro di memoria possibile. |
| <b>SSS motore non reale (compresso)</b> | Texture di nomi e pacchetti da utilizzare nel motore irreale con il minor ingombro di memoria possibile, sostituendo la mappa di opacità con la dispersione del sottosuolo. |
| <b> Variabile successiva (Rugosità metallica)</b> | Predefinito per il modulo di rendering Vray con flusso di lavoro PBR. |
| <b>Variazione successiva (Lucentezza Specular)</b> | Predefinito per il modulo di rendering Vray con flusso di lavoro non PBR. |
| <b> Vray UDIM Legacy (Rugosità metallica)</b> | Predefinito per il modulo di rendering Vray (convenzione di denominazione UDIM). |
