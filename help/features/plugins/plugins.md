# Plug-in

Substance 3D Painter dispone di un’API di scripting dedicata che consente di creare plug-in personalizzati per aggiungere funzionalità e comportamenti personalizzati.\
I plug-in vengono scritti in JavaScript e possono essere combinati con il linguaggio QML per creare un&#39;interfaccia personalizzata all&#39;interno dell&#39;applicazione. Per ulteriori dettagli su quanto è disponibile nell’API, consulta la documentazione sullo scripting (disponibile dal menu Aiuto dell’applicazione).

## Plug-in predefiniti

Substance 3D Painter ha due plug-in predefiniti che mostrano diversi.

* [Salvataggio automatico](autosave.md)
* [Resources Updater](resources-updater.md)
