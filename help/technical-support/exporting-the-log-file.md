# Esportazione del file di registro

Questa pagina spiega come trovare il file di registro dell’applicazione e come condividerlo per richiedere assistenza.

## Recupero del file di registro

Esistono due modi per ottenere il file di registro:

### Esportazione del file di registro dall&#39;applicazione

Il file di registro può essere esportato direttamente dall&#39;applicazione accedendo al menu **Aiuto** e selezionando l&#39;azione **Esporta registro**.

![](../assets/screenshot-20210622-195334.png)

### Recupero manuale del file di registro sul disco

Se l&#39;applicazione non viene avviata, non sarà possibile esportare il file di registro. Fortunatamente il file di registro può essere individuato manualmente sul disco. Passa alla cartella corrispondente al tuo sistema operativo di seguito e recupera manualmente il file **log.txt**.
