# Riflesso obiettivo

![](../../assets/v12_post_flare.jpg)

Simula gli artefatti ottici prodotti quando le sorgenti di luce interagiscono con gli elementi dell’obiettivo della fotocamera, creando aloni, striature e riflessi dei fantasmi.

| <b>Parametro</b> | <b>Descrizione</b> |
| --- | --- |
| <b>Risoluzione</b> | Imposta la risoluzione di rendering interna per l’effetto riflesso lente. Valori più alti producono striature più nitide ma possono influire sulle prestazioni. |
| <b>Fotocamera</b> | Seleziona il modello di fotocamera usato per simulare il riflesso. I valori possibili sono:<ul data-preserve-html="true"> <li data-preserve-html="true"><b>Obiettivo panoramico</b> (lunghezza focale più corta) </li> <li data-preserve-html="true"><b>Teleobiettivo</b> (lunghezza focale più lunga).</li> </ul> |
| <b>Importo</b> | Controlla l’intensità complessiva dell’effetto riflesso. Il valore può superare 1,0 per aumentare l’intensità. |
| <b>Soglia</b> | Determina la luminosità minima dell’immagine necessaria per generare un bagliore. Valori più bassi producono riflessi in più aree, mentre valori più alti limitano l’effetto alle sorgenti di luce molto luminose. |
| <b>Scala apertura</b> | Ridimensiona la dimensione dell&#39;apertura utilizzata per il calcolo del bagliore, influendo sulla dimensione complessiva degli elementi del bagliore. |
| <b>Spessore rivestimento</b> | Simula il rivestimento antiriflesso sugli elementi dell’obiettivo. Il thickness di rivestimento influisce sulla dispersione della luce e quindi cambia il colore dei riflessi. |
| <b>Rivestimento IOR</b> | Simula l’indice di rifrazione dell’obiettivo: il modo in cui la luce passa attraverso il suo thickness. Valori più bassi producono fantasmi più concentrati. |
| <b>Scala di Occlusione</b> | Imposta le dimensioni dell&#39;area centrale interessata. |
| <b>smoothness Occlusione</b> | Controlla la graduale dissolvenza del riflesso dell’obiettivo. Valori più alti creano transizioni più morbide. |
| <b>Fantasmi univoci</b> | Definisce la variazione delle forme dei bagliori. Valori più alti possono influire in modo significativo sulle prestazioni. |
| <b>Scala posizione fantasma</b> | Controlla la diffusione e le dimensioni degli aloni dei riflessi. |
| <b>Texture apertura</b> | Definisce la forma dell&#39;apertura dell&#39;obiettivo utilizzata per generare il motivo del bagliore. La texture controlla le forme diffrazione e fantasma. |
