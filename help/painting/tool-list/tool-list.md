# Elenco strumenti

Questa pagina descrive in dettaglio tutti gli strumenti di pittura disponibili e come utilizzarli.

| *Strumento* | *Descrizione* |

| <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r3-column-c0_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/icon-projection.png" width="100px"/></div> | [Proiezione](projection.md) consente di applicare un materiale o una texture allineati al punto di vista corrente. |
