# Forzare la GPU esterna sul sistema operativo Mac

In Mac OS Mojave, è possibile specificare per applicazione l’utilizzo della GPU esterna. È possibile che le prestazioni e la stabilità di Substance 3D Painter migliorino con questa impostazione attivata.

Per ulteriori informazioni, consulta la [documentazione Apple](https://support.apple.com/en-us/HT208544).

Per attivarla:

1. Chiudi Substance 3D Painter se è già in esecuzione.
1. Seleziona Substance 3D Painter nel Finder; si trova nella cartella **Applicazioni**&#x200B;**.**
1. Premi **Comando-I** oppure fai clic con il pulsante destro del mouse sull&#39;applicazione **Substance 3D Painter** e scegli **Ottieni informazioni**.
1. Nella nuova finestra, attiva l&#39;impostazione **Preferisci GPU esterna**.
1. Riavviate Substance 3D Painter.

>[!NOTE]
>
> Questa impostazione non sarà visibile se una eGPU non è connessa o se la versione corrente di MacOS è troppo vecchia.
