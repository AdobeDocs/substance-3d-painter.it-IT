# La GPU ha driver obsoleti

![](../../../assets/driver-outdated.png){width="500px"}

Quando si avvia Substance 3D Painter, può apparire una finestra a comparsa che indica che i driver della GPU sono obsoleti. Questo messaggio indica semplicemente che il software richiede una versione minima dei driver GPU da installare. Quando possibile, si consiglia di aggiornare i driver della GPU all&#39;ultima versione disponibile per ottenere la migliore esperienza di lavoro.

| *Fornitore* | *Collegamento* |
| --- | --- |
| **NVIDIA** | [http://www.nvidia.com/Download/index.aspx](http://www.nvidia.com/Download/index.aspx?lang=en-us) <ul data-preserve-html="true"><li data-preserve-html="true"><strong> GeForce </strong>: versione consigliata per &quot;Driver Studio&quot; (SD).</li><li data-preserve-html="true"><strong> Quadro </strong>: versione consigliata: &quot;Optimal Driver for Enterprise&quot; (ODE).</li></ul> |
| **AMD** | <http://support.amd.com/en-us/download> |
| **Intel** | <https://downloadcenter.intel.com/> |

>[!NOTE]
>
> Alcuni computer <b>possono disporre di due GPU</b>: una integrata (come un chipset Intel) e una dedicata (come una scheda grafica Nvidia). <b>Entrambi</b> devono essere <b>aggiornati </b>per ridurre il rischio di bug in Painter.
