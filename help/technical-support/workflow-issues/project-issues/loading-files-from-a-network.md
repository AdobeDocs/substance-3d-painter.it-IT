# Caricamento di file da una rete

Substance 3D Painter non supporta i percorsi di rete perché richiede l&#39;**autenticazione dell&#39;account**, operazione non consentita dal software.\
I percorsi devono pertanto essere **mappati** / **montati** dal sistema operativo.

* **Windows**: <http://www.laptopmag.com/articles/map-network-drive-windows-10>
* **MacOS**: <http://osxdaily.com/2010/09/20/map-a-network-drive-on-a-mac/>
* **Linux**: <http://superuser.com/questions/145191/how-do-i-map-a-drive-network-share-using-the-linux-terminal>
