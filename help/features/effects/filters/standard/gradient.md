## Descrizione

Il filtro Sfumatura rimappa i valori in scala di grigio di un’immagine utilizzando una sfumatura personalizzata.

Può essere utilizzato per modificare i valori di un’immagine in scala di grigio o per colorare l’input in scala di grigio mappandolo su una sfumatura personalizzata.

</td>
</tr>

<a name="parameters"></a>

## Parametri

| Nome parametro | Descrizione |
| --- | --- |
| <b>Sfumatura visualizzazione (debug):</b> | Attiva/disattiva la visualizzazione di debug della sfumatura. |
| <b>Quantità colore:</b> | Regolate il numero di colori usati nella sfumatura. |
| <b>Fusione colore in lineare:</b> | Attiva/disattiva la fusione lineare dei colori. |
| <b>Colore 1:</b> | Selezionate il primo colore. |
| <b>Posizione colore 1:</b> | Regolate la posizione del primo colore. |
| <b>Colore 2:</b> | Selezionate il secondo colore. |
| <b>Posizione colore 2:</b> | Regolate la posizione del secondo colore. |
| <b>Colore N:</b> | Selezionate l’ennesimo colore. |
| <b>Posizione N Colore:</b> | Regolate la posizione dell’ennesimo colore. |

### Trasformazione input

| Nome parametro | Descrizione |
| --- | --- |
| **Modalità scala di grigi:** | Selezionate la modalità di trasformazione in scala di grigio. Potete scegliere tra Desaturazione, Luma, Media, Max e Min. |
| **Intensità sfocatura:** | Regola l’entità di sfocatura dell’input. |
| **Saldo:** | Regola il bilanciamento dell&#39;input spostando il punto medio verso il bianco o il nero, in modo simile a un controllo della luminosità. |
| **Contrasto:** | Regola il contrasto dell&#39;input. |
| **Inverti:** | Attiva/disattiva l’inversione dei colori di input. |
