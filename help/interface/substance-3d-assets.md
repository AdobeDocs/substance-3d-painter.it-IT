# Substance 3D Assets

![](../assets/v10_banner_3d_assets_2-1.jpg)

L&#39;ancoraggio <b>Substance 3D Assets</b> consente di sfogliare la libreria online con lo stesso nome direttamente nell&#39;applicazione. La libreria originale è disponibile al seguente indirizzo: <https://substance3d.adobe.com/assets>

>[!NOTE]
>
> La finestra Substance 3D Assets non è disponibile con la versione Steam dell&#39;applicazione.

## Posizione

Per impostazione predefinita, la finestra è ancorata come scheda accanto alla finestra Risorse generali. Se la finestra è chiusa, può essere riaperta dalla barra degli strumenti di ancoraggio all’estrema destra dell’interfaccia.

![](../assets/v10_3dassets_location_tab.png)

![](../assets/v10_3dassets_location_dock.png)

### Esplorazione delle risorse

Per sfogliare le risorse, puoi utilizzare l&#39;interfaccia disponibile all&#39;interno della finestra. Nella parte superiore è visualizzato un campo di ricerca per definire meglio la ricerca ed è disponibile anche un filtro.

![](../assets/v10_3d_assets_search.jpg)

### Download delle risorse

Una volta fatto clic sul pulsante di download di una risorsa, il download inizierà e sarà visualizzato all&#39;interno del gestore download della finestra. Per visualizzarla basta fare clic sul pulsante in basso a sinistra della finestra.

Questo elenco visualizza solo le risorse scaricate durante la sessione corrente dell&#39;applicazione.

Una volta scaricata correttamente una risorsa, verrà visualizzata nella normale finestra <b>Risorse</b>.

![](../assets/v10_3d_assets_download.png)

>[!NOTE]
>
> La posizione in cui vengono scaricate le risorse dipende dalla libreria predefinita. Questa posizione può essere modificata nelle preferenze, vedere la [pagina della documentazione](assets/adding-a-new-library.md) dedicata.

### Menu di controllo

Il pulsante in basso a destra nella finestra offre alcune azioni:

* <b>Apri percorso cartella</b>: apri Esplora file nel percorso della libreria corrente. Ciò consente di visualizzare su disco le risorse scaricate (incluse le sessioni passate).
* <b>Ricarica pagina</b>: ricarica l&#39;interfaccia all&#39;interno della finestra.
* <b>Pagina precedente</b>: passa all&#39;interfaccia precedente all&#39;interno della finestra.
* <b>Pagina successiva</b>: passa all&#39;interfaccia successiva all&#39;interno della finestra.

![](../assets/v10_3d_assets_menu-1.png)
