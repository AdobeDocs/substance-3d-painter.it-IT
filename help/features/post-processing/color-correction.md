# Correzione colore

![](../../assets/color-correction-example.jpg)![](../../assets/color-correction.png)

Parametri di correzione colore:

| *Impostazione* | *Descrizione* |
| --- | --- |
| **Saturazione** | Controlla l’intensità/saturazione del colore nella finestra della vista. Usa una saturazione a 0 per ottenere un rendering in scala di grigi. |
| **Contrasto** | Controlla la differenza tra colori chiari e scuri. |
| **Luminosità** | Controlla la luminosità dei colori. |
| **Polarizzazione** | Scostamento globale della luminosità della finestra della vista. |
| **Rapporto tonalità seppia** | Parametro avanzato per applicare un effetto seppia alla finestra della vista. |
| **Temperatura bilanciamento bianco (K)** | Temperatura dei colori, in Kelvin. Il valore predefinito è 6500K, corrispondente alla luce del giorno. [Per ulteriori informazioni, visitare Wikipedia](https://en.wikipedia.org/wiki/Color_temperature). |
