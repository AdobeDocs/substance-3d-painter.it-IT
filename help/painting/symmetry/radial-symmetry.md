# Simmetria radiale

La simmetria radiale duplica le tracce o il contenuto del livello di riempimento in modo radiale attorno a un asse:

![](../../assets/radial-demo.gif)

## Usate il manipolatore per posizionare l’asse di simmetria

È possibile accedere alle impostazioni di visualizzazione Simmetria dal <b>pulsante Impostazioni simmetria</b> nella barra degli strumenti contestuale nella parte superiore della vista 3D. Sotto le impostazioni di visualizzazione, è possibile attivare e personalizzare il manipolatore. Trascinate le maniglie del manipolatore nella vista 3D per modificare la posizione dell’asse di simmetria.

![Schermata del pannello delle impostazioni di simmetria radiale con il manipolatore visibile nella finestra della vista.](../../assets/RadialSymmetryManip.png){width="600px"}

## Parametri di simmetria radiale

![Schermata della sezione Simmetria del pannello Proprietà](../../assets/FillSymmetry_1.png){width="300px"}

| *Parametro* | *Descrizione* |
| --- | --- |
| <b>Asse</b> | Definisce l’asse della scena utilizzato per eseguire la simmetria. |
| <b>Capovolgi copia</b> | Capovolgere le copie alternate sull&#39;asse U o V. Questo è utile quando si utilizza la simmetria su contenuti che hanno una direzione come il testo. |
| <b>Posizione asse: X, Y, Z</b> | Definisce l&#39;offset dell&#39;asse nel progetto. Questo valore può essere modificato con i cursori o con il manipolatore (vedere sopra). |
| <b>Mostra asse</b> | Se questa opzione è attivata, nella finestra della vista sarà visibile una linea trasparente che rappresenta l’asse di simmetria. |
| <b>Mostra intersezione</b> | Se questa opzione è attivata, verrà tracciato un punto sulla trama nella finestra della vista per mostrare dove l’asse di simmetria interseca la trama. |
| <b>Mostra cursore (strumento pennello)</b> | Se questa opzione è attivata, sull&#39;altro lato della simmetria verrà visualizzato un secondo cursore per indicare quando verrà eseguito il disegno. |
| <b>Nascondi durante il disegno (strumento Pennello)</b> | Se questa opzione è attivata, il secondo cursore viene nascosto mentre è in corso l’operazione di disegno (fino al rilascio del clic del mouse). |
| <b>Mostra manipolatore posizione asse</b> | Attiva/disattiva la visibilità del manipolatore nella finestra della vista. |
| <b>Dimensione manipolatore</b> | Controlla le dimensioni del manipolatore nella finestra della vista. |
