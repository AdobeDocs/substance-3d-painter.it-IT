# Personalizzazione del layout

Alcune opzioni di interfaccia, come le librerie secondarie, la larghezza ridotta e le dimensioni delle miniature, consentono di modificare il layout del pannello Risorse in base alle proprie esigenze.

>[!NOTE]
>
> È possibile scorrere le risorse utilizzando la rotellina del mouse o manipolando la barra di scorrimento. In alternativa, un metodo alternativo per scorrere in qualsiasi finestra di Painter consiste nel **tenere premuto Ctrl+Alt e trascinare** all&#39;interno del pannello desiderato.

Ancoraggio e orientamento

Alla prima apertura di Painter dopo l’installazione, la finestra Risorse è ancorata verticalmente a sinistra dell’app. Tuttavia, può essere disancorata e posizionata orizzontalmente. Inoltre, se si utilizzano altre finestre [della libreria secondaria](sub-library-tab.md), anche queste possono essere ancorate e disancorate in base alle proprie esigenze.

![](../../assets/00-02-docking.gif){width="600px"}

## Larghezza ridotta

Le sue dimensioni possono essere ridotte, nel qual caso i tipi di risorse vengono compressi in un unico menu in cui è possibile selezionare una o più opzioni.

![](../../assets/00-03-reduced.jpg)

## Dimensione miniatura

Le dimensioni delle miniature delle risorse possono essere regolate utilizzando l&#39;icona più a sinistra, che offre le opzioni Piccolo, Medio (impostazione predefinita), Grande ed Elenco.

![](../../assets/00-04-thumbs.jpg){width="600px"}
