# Pendenza sfocatura

    <td style="border: 0;" valign="top">Descrizione<br>Il filtro Sfocatura Pendenza crea un effetto di macchie o dissolvenza, particolarmente evidente sui bordi ad alto contrasto tra i colori.<br>Viene utilizzato direttamente su un livello texture per sfocare materiali completi o texture specifiche oppure su una maschera per applicare l’effetto di striscio alla maschera. ## Input

| Nome di input | Descrizione |
| --- | --- |
| **Disturbo personalizzato:** Scala di grigi | Usate una texture personalizzata o un punto di ancoraggio come disturbo personalizzato. |

## Parametri

| Nome parametro | Descrizione |
| --- | --- |
| **Valore di inizializzazione:** | Assegna un valore casuale per creare una variazione diversa senza modificare le impostazioni generali. |
| **Intensità:** | Regolate l’intensità della sfocatura. |
| **Divisore intensità:** | Selezionate la modalità di divisione dell’intensità della sfocatura. |
| **Metodo fusione:** | Selezionate il metodo di fusione utilizzato dalla sfocatura pendenza. |
| **Qualità:** | Regolate la qualità dell’effetto. |

### Parametri di origine

| Nome parametro | Descrizione |
| --- | --- |
| **Tipo di origine:** | Consente di specificare se la sorgente utilizza il disturbo predefinito, l’input precedente o un disturbo personalizzato. |
| **Sfocatura:** | Regolate l’intensità della sfocatura del disturbo o dell’input sorgente. |
| **Posizione:** | Regola il punto medio del disturbo o dell&#39;input sorgente, in modo simile a un controllo della luminosità. |
| **Contrasto:** | Regola il contrasto del disturbo o dell&#39;input sorgente. |
| **Lavorazione origine:** | Regola l&#39;Affiancamento del disturbo o dell&#39;input sorgente. |
