## Descrizione

Il filtro Acquerello MatFX stilizza la sorgente con un effetto acquerello.

Viene utilizzato sui livelli texture per creare effetti di dispersione con effetto acquerello, interazioni tra carta e bordi dipinti.

## Parametri

| Nome parametro | Descrizione |
| --- | --- |
| <b>Opacità Pittura:</b> | Regolate l’opacità della pittura. |
| <b>Assorbimento carta:</b> | Regolate la forza con cui la carta assorbe la pittura. |
| <b>Tipo di accumulo:</b> | Selezionare il metodo di accumulo. |
| <b>Distribuzione bordi:</b> | Regolate la diffusione dei bordi della pittura. |
| <b>Densità bordi:</b> | Regolate la densità dei bordi della pittura. |
| <b>Mostra bordi pittura incrociata:</b> | Attiva/disattiva la visualizzazione dei bordi delle pitture trasversali. |
| <b>Nascondi carta:</b> | Attiva/disattiva la visibilità della texture carta. |
| <b>Carta personalizzata:</b> | Attivare/disattivare l’uso di una texture personalizzata. |
