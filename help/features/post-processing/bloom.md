# Fiori

![](../../assets/v12_post_bloom.jpg)

Crea un leggero bagliore intorno alle aree luminose della scena. Simula la dispersione di luce in un’aura luminosa.

| <b>Parametro</b> | <b>Descrizione</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>Importo</b> | Controlla l’intensità dell’effetto fioritura. Valori più elevati producono un bagliore più pronunciato intorno alle aree luminose. |
| <b>Soglia</b> | Imposta il livello di luminosità minimo richiesto per attivare la fioritura. Baglieranno solo i pixel più luminosi di questo valore. Una soglia pari a 1,0 indica che fioriranno solo i pixel più luminosi del bianco visualizzato sullo schermo. |
| <b>Decadimento</b> | Determina la distanza di diffusione della fioritura dalle aree luminose. I valori più bassi creano un bagliore più compatto, mentre i valori più alti diffondono l’effetto su un’area più ampia. |
