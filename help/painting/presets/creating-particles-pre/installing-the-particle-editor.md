# Installazione dell&#39;editor particelle

Per creare e modificare il comportamento del sistema di particelle, è necessario utilizzare l’editor PopcornFX.\
Scarica l&#39;editor da uno dei seguenti collegamenti: [Mirror 1](http://downloads.popcornfx.com/updates/1.5.5.20787/PopcornFx-Editor_Setup_v1.5.5.20787.exe), [Mirror 2](https://www.dropbox.com/s/z1vwzvk2ywlug4p/PopcornFx-Editor_Setup_v1.5.5.20787.exe?dl=1).

>[!NOTE]
>
> Painter utilizza una versione precedente dell’editor perché richiede il supporto di una versione specifica. Per ulteriori informazioni, vedere anche il [wiki ufficiale](https://wiki.popcornfx.com/).
