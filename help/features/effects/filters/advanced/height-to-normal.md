## Descrizione

Il filtro Height normale genera dati normali accurati in base al canale del height.

Viene utilizzato su un livello texture per convertire le informazioni del height in dati normali.

<a name="parameters"></a>

## Parametri

| Nome parametro | Descrizione |
| --- | --- |
| <b>Sovrascrivi normale esistente:</b> | Attiva/disattiva la sovrascrittura dei dati normali esistenti. |
| <b>Usa unità globali:</b> | Attiva/disattiva l’utilizzo di unità globali per la conversione. |
| <b>Intensità normale:</b> | Se **Usa unità globali** è **False**, utilizzare questa opzione per regolare l&#39;intensità dei dati normali generati. |
| <b>Dimensioni superficie (cm):</b> | Se **Usa unità mondiali** è **True**, utilizzare questa opzione per regolare la larghezza o il height, a seconda di quale sia maggiore, della superficie rappresentata. |
| <b>Profondità Height (cm):</b> | Se **Usa unità globali** è **Vero**, utilizzarlo per regolare l&#39;intervallo height massimo della superficie. |
