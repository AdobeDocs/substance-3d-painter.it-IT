## Descrizione

Il filtro Ombra esterna crea un’ombra esterna.

Viene utilizzato su un livello di pittura per creare ombre esterne in base ai tratti colorati.

## Parametri

| Nome parametro | Descrizione |
| --- | --- |
| <b>Angolo:</b> | Regolate l’angolo di ombra. |
| <b>Distanza:</b> | Regola la distanza dell’ombra. |
| <b>Dimensioni:</b> | Regola le dimensioni dell’ombra. |
| <b>Pagine affiancate:</b> | Regolate la diffusione dell’ombra. |
| <b>Opacità:</b> | Regolate l’opacità dell’ombra. |
| <b>Colore:</b> | Regolate il colore dell’ombra. |
