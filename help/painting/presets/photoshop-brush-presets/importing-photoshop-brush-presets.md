# Importazione di pennelli predefiniti di Photoshop

Questa pagina descrive come importare un file ABR in Substance 3D Painter.

1. <b>Aprire la finestra di importazione delle risorse.</b>

   La finestra Importa risorsa può essere aperta in tre modi diversi:

   * Trascina il file ABR nel pannello Risorse.
   * Utilizzare <b>File > Importa risorse </b> nel menu Principale.
   * Utilizza il pulsante <b>+ </b> nel pannello Risorse.
1. <b>Aggiungere il file ABR alla finestra Importa risorse.</b>

   Se non hai trascinato il file ABR nella finestra Risorse per aprire la finestra di importazione, per impostazione predefinita sarà vuoto.

   Per aggiungere il file ABR, puoi:

   * **Trascinare** il file ABR nella finestra.
   * Fare clic sul pulsante **Aggiungi risorse** per selezionare e caricare il file ABR.

   >[!NOTE]
   >
   > ![](../../../assets/shelf-import-error.png)
   > 
   > In caso di problemi, accanto al file ABR può essere visualizzata un’icona di avviso. Ad esempio:
   > 
   > * Nessun predefinito compatibile trovato. Per ulteriori informazioni, consultate l&#39;elenco [Compatibilità dei parametri dei pennelli di Photoshop](photoshop-brush-parameters-compatibility.md).
   > * Impossibile leggere il file (ad esempio, è danneggiato).
1. <b>Selezionare la modalità di importazione del file ABR.</b>

   Nella parte inferiore della finestra Importa risorse, scegli dove caricare il file ABR:

   * <b> progetto</b>: il file ABR verrà caricato nel progetto attualmente aperto. I pennelli saranno disponibili solo quando il progetto corrente è aperto e sono allegati al file di progetto.
   * <b> Sessione</b>: il file ABR verrà caricato in memoria. I predefiniti del pennello saranno disponibili fino a quando l’applicazione non verrà chiusa.
   * Libreria <b></b>: il file ABR verrà copiato nello scaffale del disco. I predefiniti dei pennelli saranno disponibili ogni volta che si apre Painter, per tutti i progetti.

   ![](../../../assets/import-location.png)
1. <b>Accedere ai pennelli predefiniti dallo scaffale.</b>

   ![](../../../assets/shelf-demo.png)

   Se non si sono verificati problemi durante l&#39;importazione dei pennelli predefiniti, verranno visualizzati nella finestra [Risorse](../../../interface/assets/assets.md).

   >[!NOTE]
   >
   > Se un pennello predefinito è basato su una bitmap, l’immagine che utilizza sarà disponibile anche nella sezione Alpha del Ripiano con lo stesso nome del pennello predefinito.
