# Porzioni UV

![](../../assets/banner-uvtiles.jpg)

Le porzioni UV consentono di creare texture su più set di texture, in diversi intervalli UV, all’interno di un set di texture.

Per impostazione predefinita, in un flusso di lavoro tradizionale una texture viene ripetuta su ogni intervallo UV. Con i riquadri UV, ogni intervallo diventa invece una texture dedicata. Questo flusso di lavoro consente di aumentare virtualmente la risoluzione generale delle texture dividendo gli UV in più set di texture. Attualmente i riquadri UV supportano solo la convenzione di denominazione UDIM.

Per ulteriori informazioni sul flusso di lavoro delle porzioni UV, consultate le pagine seguenti:

* [Creazione di progetti](../../getting-started/project-creation.md) con il flusso di lavoro dei riquadri UV.
* Visualizzazione dei riquadri UV nella [vista 2D](../../interface/viewport/2d-view.md).
* [Maschera per porzioni UV](../../interface/layer-stack/geometry-mask.md) per migliorare le prestazioni.
* Importazione e utilizzo di [sequenze di immagini](image-sequence.md).
* Regolazione della risoluzione per porzioni UV nelle [impostazioni del set di texture](../../interface/texture-set/texture-set-settings.md).

>[!NOTE]
>
> Lavorare con i progetti UV Tile può essere impegnativo, si consiglia di utilizzare un SSD per migliorare i tempi di caricamento e le prestazioni generali. Si consiglia inoltre di impostare la posizione della cache anche su un SSD.
