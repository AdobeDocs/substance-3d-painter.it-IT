## Descrizione

Il filtro di Trasforma viene utilizzato per Trasforma (ridimensionare, ruotare, scostare) un livello.

Viene utilizzato su un livello texture o all’interno di una maschera (output in bianco e nero) per Trasforma ad esempio pattern, forme e così via.

## Parametri

| Nome parametro | Descrizione |
| --- | --- |
| <b>Modalità di ripetizione:</b> | Selezionare la modalità di ripetizione. |
| <b>Modalità capovolgimento:</b> | Selezionate la modalità di capovolgimento. |
| <b>Ridimensionamento X:</b> | Regolate il ridimensionamento X del risultato. |
| <b>Ridimensionamento Y:</b> | Regolate il ridimensionamento Y del risultato. |
| <b>Scostamento X:</b> | Regolate lo scostamento X del risultato. |
| <b>Scostamento Y:</b> | Regolate lo scostamento Y del risultato. |
| <b>Rotazione sicura riquadro:</b> | Attivate/disattivate la rotazione di sicurezza affiancata. |
| <b>Rotazione:</b> | Regolate la rotazione. |
| <b>Ridimensionamento:</b> | Regolate il ridimensionamento complessivo. |
| <b>Scostamento:</b> | Regolate lo scostamento complessivo. |
