# Menu Finestra

![](../../assets/window-menu.png)\
Il menu Finestra consente di visualizzare un elenco delle finestre e se sono visibili nell&#39;interfaccia. Potete utilizzare anche il menu della barra degli strumenti per nascondere alcune barre degli strumenti.

| Azione | Descrizione |
| --- | --- |
| **Visualizzazioni** | Elenca le finestre disponibili nell&#39;interfaccia (la casella di controllo indica se è attualmente visibile). |
| **Barre Degli Strumenti** | Elenca le barre degli strumenti disponibili nell’interfaccia (la casella di controllo indica se è attualmente visibile e consente di attivarle o disattivarle): Docks, Plugin &amp; Tools. |
| **Nascondi interfaccia utente** | Nasconde tutte le finestre e i dock dell&#39;interfaccia ed espande le finestre. |
| **Ripristina interfaccia utente** | Ripristina il layout predefinito della finestra corrente. |
