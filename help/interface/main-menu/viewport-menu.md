# Menu Finestra vista

![](../../assets/viewport-menu.png)

È possibile utilizzare il menu della finestra della vista per modificare la modalità di visualizzazione delle [finestre della vista](https://substance3d.adobe.com/).

| Azione | Descrizione |
| --- | --- |
| **Visualizza materiale** | Passa le finestre della vista alla modalità **Materiale** che mostra il modello 3D con illuminazione e ombreggiatura. |
| **Visualizza canale successivo** | Passate le finestre delle viste alla modalità Solo per visualizzare il canale successivo del set di texture. |
| **Visualizza canale precedente** | Passate dalla finestra delle viste alla modalità Solo per visualizzare il canale Set texture precedente. |
| **Visualizza mappa trama successiva** | Passate dalla finestra delle viste alla modalità Solo per visualizzare il successivo tipo di mappa Mesh in forno. |
| **Visualizza mappa trama precedente** | Passate dalla finestra delle viste alla modalità Solo per visualizzare il precedente tipo di mappa della trama in forno. |
| **Mostra intera trama** | Regolate la videocamera della finestra della vista per centrarla sul modello 3D. |
| **Maschera veloce abilitata** | Per ulteriori informazioni, vedere la pagina [Maschera veloce](../../painting/tool-list/quick-mask.md). |
| **Modifica maschera veloce** | Per ulteriori informazioni, vedere la pagina [Maschera veloce](../../painting/tool-list/quick-mask.md). |
| **Inverti maschera veloce** | Per ulteriori informazioni, vedere la pagina [Maschera veloce](../../painting/tool-list/quick-mask.md). |

Per ulteriori informazioni sulle modalità di visualizzazione, vedere [Impostazioni di visualizzazione](../display-settings/display-settings.md).

Per ulteriori informazioni sulla maschera veloce, consultate la [pagina dedicata](../../painting/tool-list/quick-mask.md).
