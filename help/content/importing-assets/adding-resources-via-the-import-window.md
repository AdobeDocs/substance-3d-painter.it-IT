# Aggiunta di risorse tramite la finestra di importazione

## Apertura della finestra di importazione

Esistono tre modi diversi per aprire la finestra di importazione in Substance 3D Painter:

* Tramite la voce di menu **File > Importa risorse...**

![](../../assets/05-01-importfilemenu.jpg)

* Tramite il **pulsante dedicato** nella finestra Risorse

![](../../assets/05-03-importbutton.jpg)

* Tramite **trascinamento** di uno o più file/cartelle nella finestra Risorse

![](../../assets/05-02-importdnd.gif){width="700px"}

## Configurazione della finestra di importazione

![](../../assets/05-04-importwindow.jpg)

* **1 - Aggiungi risorse**: consente di selezionare altri file da importare, che verranno aggiunti all&#39;elenco visualizzato nella finestra di importazione.
* **2 - Rimuovi risorse selezionate:** Rimuove i file selezionati nell&#39;elenco.
* **3 - Filtro a discesa**: consente di filtrare l&#39;elenco dei file in base all&#39;utilizzo. Questa opzione è utile per isolare le risorse con il tipo &quot;indefinito&quot;.
* **4 - Utilizzo**: sono disponibili diversi tipi di utilizzo. L’elenco degli usi proposti può variare in base al formato di file importato. L’utilizzo può essere preselezionato per il file se il formato di file ha un solo tipo di utilizzo (ad esempio, i predefiniti di Painter .sppr verranno definiti automaticamente come tali) OPPURE se è stato predefinito nel grafico di Designer originale dal suo creatore.
* **5 - Prefisso**: il prefisso può essere un percorso di cartella per definire la posizione in cui memorizzare una risorsa.
* **6 - Nome file**: nome della risorsa corrente. A volte è possibile indicare la cartella in cui è stata memorizzata la risorsa, queste informazioni non verranno utilizzate durante il processo di importazione.
* **7 - Percorso di importazione**: può essere -
  * **Sessione corrente**: in una sessione temporanea, le risorse andranno perse dopo il riavvio dell&#39;applicazione.
  * **Project &quot;project name&quot;**: nel file di progetto aperto. Risorse incorporate nel file **spp**.
  * **Shelf &quot;shelf name&quot;**: nella libreria corrente definita come scrivibile. Per ulteriori informazioni, vedere questa pagina: [Configurazione librerie](../../interface/settings/libraries-configuration.md).

È possibile selezionare più risorse nella finestra di importazione (utilizzando le normali scelte rapide di sistema) per modificarne rapidamente l’utilizzo.
