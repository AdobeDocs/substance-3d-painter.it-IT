# Colore casuale UV

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_uv_random_color.png" alt=""/><br><strong>In:</strong> utilità, maschera</td>
    <td style="border: 0;" valign="top"><strong>Descrizione</strong><br>Il generatore di colori casuali UV assegna colori unici a tinta unita a ciascuna Isola UV. Questo è spesso utile come strumento diagnostico con trame complesse.<br><br>Il colore casuale UV può essere utilizzato per creare una maschera (output in bianco e nero) o direttamente come livello di riempimento per applicare la variazione di colore alla trama in base alle Isole UV, ad esempio per casualizzare ogni tavola di un pavimento in legno.</td>
  </tr>
</table>

## Input

| Nome di input | Descrizione |
| --- | --- |
| **Sfumatura personalizzata** | Utilizzate una mappa sfumatura per definire l’intervallo di colori. |

## Parametri

<table>
  <tr>
    <th>Nome parametro</th>
    <th>Descrizione</th>
  </tr>
  <tr>
    <td><strong>Seed</strong></td>
    <td>Impostate il valore di partenza utilizzato per generare la texture del dirt. <br><ul><li>Fate clic su Casuale per passare a un altro valore di inizializzazione casuale.</li><li>Fate clic sulla matita per visualizzare il valore iniziale corrente e immettete un valore specifico.</li></ul></td>
  </tr>
  <tr>
    <td><strong>Metodo sorgente colore</strong></td>
    <td>Determina il metodo sorgente colore utilizzato. <br><ul><li><strong>Casuale</strong>: in modalità Casuale i colori vengono definiti e assegnati in modo casuale.</li><li><strong>Sfumatura personalizzata</strong>: nella modalità Sfumatura personalizzata è disponibile un input aggiuntivo per aggiungere una mappa sfumatura personalizzata dalla quale selezionare i colori.</li></ul></td>
  </tr>
</table>
