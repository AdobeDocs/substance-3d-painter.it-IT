# Ricerche salvate

Le ricerche salvate, insieme a Filtra per percorso, rappresentano un&#39;altra nuova sezione che può essere aperta all&#39;interno della finestra Risorsa. Consente di salvare le ricerche e le query più frequenti, di accedervi facilmente in qualsiasi momento e persino di aprirle come una nuova scheda di libreria secondaria che può essere ancorata separatamente.

![](../../assets/02-01-savedsearches.jpg)

Per creare una ricerca salvata, è possibile combinare diversi tipi di navigazione: è possibile digitare una query scritta nel campo di ricerca, selezionare il tipo di risorsa desiderato (o diversi tipi di risorsa) e una posizione tramite Filtra per percorso o Breadcrumbs. Tutti questi elementi possono essere salvati come singola ricerca salvata oppure suddivisi in ricerche salvate separate. Ad esempio, potreste voler creare una ricerca salvata per i pennelli che usano i tratti dinamici, in quanto si tratta di un aspetto che usate molto spesso.

>[!NOTE]
>
> Le ricerche salvate vengono salvate in un file di configurazione modificabile manualmente. Per ulteriori informazioni, consulta [Aggiunta manuale di ricerche salvate](../../pipeline-and-integration/resource-management/adding-saved-searches-manually.md).

Una volta creata, la ricerca salvata verrà visualizzata nell&#39;elenco delle ricerche. È possibile fare clic con il pulsante destro del mouse sulla scheda per creare una nuova scheda della libreria secondaria, rinominarla o eliminarla.

![](../../assets/02-02-savesearch.gif)

È inoltre possibile visualizzare informazioni sul contenuto della ricerca passando il mouse sopra il tag di ricerca nel campo di ricerca.

![](../../assets/02-03-searchinfo.jpg)
