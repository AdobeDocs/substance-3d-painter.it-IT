# Problemi con le GPU Nvidia sulle versioni recenti del sistema operativo Mac

In Mac OS, Apple fornisce i driver della GPU convalidandoli dopo che sono stati forniti dal costruttore della GPU. Da Mac OS Mojave, Apple non ha ancora convalidato alcun nuovo driver per le recenti GPU Nvidia. Sfortunatamente, per funzionare correttamente, Substance 3D Painter deve disporre di driver GPU aggiornati.

Per ulteriori informazioni, consulta la seguente pagina:

* [Elenco delle GPU supportate nel sistema operativo Mac](https://support.apple.com/en-us/HT208898) .
* [Utilizzo di una GPU esterna nel sistema operativo Mac](https://support.apple.com/en-us/HT208544) .
